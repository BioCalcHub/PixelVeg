Formula Reference
ExG — Excess Green Index
2·g − r − b
Emphasises green vegetation; correlates with chlorophyll. Range ≈ −1 to 1.
GLI — Green Leaf Index
(2·G − R − B) / (2·G + R + B)
Uses raw 0–255 values. Positive → green biomass.
VARI — Visible Atm. Resistant Index
(G − R) / (G + R − B)
Reduces lighting effects. Proxy for green vegetation fraction.
GEI — Green Excess Index
g − (r + b) / 2
Simple normalised version; easy to compute by hand.
RGR — Red / Green Ratio
R / G
Low → healthy green; high → stress or senescence.
Normalisation:
r = R/255   g = G/255   b = B/255
lowercase = normalised (0–1) · uppercase = raw (0–255)
